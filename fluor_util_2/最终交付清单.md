## 核心API汇总

### FragmentLibrary 类

```python
library = FragmentLibrary('fluo_fragment_library.pkl')
donors = library.get_donors()          # 获取供体列表
acceptors = library.get_acceptors()    # 获取受体列表
linkers = library.get_linkers()        # 获取连接子列表
library.add_donor(smarts, name)        # 添加供体
library.save_library(path)             # 保存片段库
```

### FragmentIdentifier 类

```python
identifier = FragmentIdentifier(library)
annotation = identifier.identify(smiles)     # 识别片段
has_donor = identifier.has_donor(smiles)     # 检查供体
has_acceptor = identifier.has_acceptor(smiles)  # 检查受体
```

### ScaffoldMatcher 类

```python
matcher = ScaffoldMatcher()
bm = matcher.get_bm_scaffold_smiles(smiles)  # 提取BM骨架
csk = matcher.get_csk_scaffold_smiles(smiles)  # 提取CSK骨架
sim = matcher.compute_tanimoto_similarity_smiles(s1, s2)  # 计算相似度
matches = matcher.fuzzy_match(scaffold, library, threshold=0.5)  # 模糊匹配
```

### MoleculeProcessor 类

```python
processor = MoleculeProcessor(library)
mol, annotation = processor.process_molecule(smiles, output_path)  # 处理单分子
results = processor.batch_process(input_csv, output_dir)  # 批量处理
```

## 使用方式

### Python API

```python
from fluo_utils import create_default_library, MoleculeProcessor

library = create_default_library()
processor = MoleculeProcessor(library)
mol, annotation = processor.process_molecule('CN(C)c1ccccc1', 'output.sdf')
```

### 命令行

```bash
# 识别分子
python fluo_utils.py identify "CN(C)c1ccccc1"

# 处理分子
python fluo_utils.py process "CN(C)c1ccccc1" -o output.sdf

# 批量处理
python fluo_utils.py batch input.csv output_dir/
```

## 设计特点

1. **模块化设计**：每个功能独立成类，便于维护和扩展
2. **不增加原子**：分子处理过程不会在输入分子上增加原子
3. **保留完整性**：输出SDF保留原始分子结构
4. **灵活配置**：支持自定义片段库和匹配参数
5. **批量处理**：支持大规模分子库的高效处理
6. **多接口支持**：支持Python API和命令行两种使用方式

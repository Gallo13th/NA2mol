# Paper reproduction assets

This directory contains only the exported KRAS G-quadruplex ThT panel assets and the plotting script used for the current manuscript case study. The case-study structures, generated library, prioritisation tables and assay source data are stored under `casestudy/kras_g4/` and `experimental_data/`.

The removed G4LDB bridge-analysis, multi-target receptor/ligand screening, pair-docking, intermediate renders and duplicate figure exports are archived in `/tmp/rna2smol_g4tasks_backup_local_20261014.tar.gz` locally and in `~/rna2smol_g4tasks_backup_20261014.tar.gz` on the reproduction server.

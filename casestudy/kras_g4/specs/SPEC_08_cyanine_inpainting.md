# SPEC 08 — KRAS G4 花菁分子 Inpainting 精确复现

> 目标:精确复现实验筛出的花菁配体。基础库(10094分子)已就绪。

## 1. 目标分子

`CCN1C=C/C(=C/C=C/c2cc[n+]3ccccc3n2)c2ccccc21`(25重原子,净电荷+1)

拆解:
```
CC N1C=C/C(=C/ C=C/ c2cc[n+]3ccccc3n2) c2ccccc2 1
└二乙胺┘└─喹啉A─┘  └共轭桥┘  └──喹啉鎍C──┘
```

- **喹啉A**(供体端,中性):模型可生成(12.4%),**本 spec 固定它做种子**
- **共轭桥**(C=C-C=C):模型可生成(16.5%),由模型生成
- **喹啉鎍C**(受体端):模型不生成(0%),由模型作为取代基补出(正确取代时自然鎍化)
- **二乙胺**(N-乙基):模型可生成(12.0%),由模型生成

**用户决策**:固定喹啉(中性),不固定喹啉鎍。喹啉骨架定死后,正确的取代基(共轭链→喹啉→二乙胺)自然组装出目标。

## 2. 方案

### Step1: 种子构造
- 种子 = **中性喹啉**`c1ccc2ncccc2c1`(9重原子)或其带1,2-位取代基形式
- 3D来源(两种,都做):
  - (a) 从基础库 1248 个含喹啉分子提取喹啉环坐标(有 G4 口袋 3D)
  - (b) RDKit 构造 + 平移到 BER101 质心(33.1,36.2,32.6)
- total_n = 25(目标分子大小)

### Step2: Inpainting 生成
- `sample_by_seed`:固定喹啉环 9 原子(fixed_atom_mask/pos/types)
- 模型生成剩余 ~16 原子(共轭链+喹啉鎍端+二乙胺)
- 4 卡并行(不同 seed),每卡 ~2500 分子
- 原子数限制 20-28(或收紧到 23-27)

### Step3: 筛选(逐级)
1. **含喹啉鎍**`c1cc[n+]2ccccc2c1`(模型补出了鎍端?)
2. **含共轭链** C=CC=C
3. **含二乙胺** N(CC)CC
4. Tanimoto vs 目标(精确复现:>0.9;高相似:>0.5)
5. canonical SMILES == 目标?

### Step4: 若未精确复现的递进策略
- 粒度加深:固定"喹啉+共轭链首原子"(11原子),或固定更多
- 多种子变体:喹啉不同位置(2-位/4-位取代位点朝向)
- 大规模:更多轮次/更多种子

## 3. 验收
1. inpainting 跑通(喹啉固定的 sample_by_seed)
2. 产物含喹啉鎍的比例(模型能否补出鎍端)
3. **精确复现**:canonical SMILES == 目标?(或 Tanimoto>0.9)
4. 若未复现,报告最高 Tanimoto 与差距

## 4. 不做
- 不改模型/checkpoint/采样权重
- 不嫁接(经验教训:8hzk 嫁接被判定不合法;元素替换可接受若需要)

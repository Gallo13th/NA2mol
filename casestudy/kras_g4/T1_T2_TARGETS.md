# KRAS G4 复现目标分子档案

> 记录本研究在 KRAS G4 (G-四链体) 靶点上尝试复现的两个配体分子,包含结构、目标、复现路径、最终判定。

## 靶点背景

- 结构源: 7X8M (berberine) / 7X8O (coptisine)，均为 NMR,10 MODEL，KRAS G-四链体
- 口袋: MODEL 1, **BER102 (7X8M)** / **KPT102 (7X8O)** 均为 well-buried 位点(buried 10/10 方向),中心 (34.5,23.4,28.0) / (29.5,21.0,29.1)
- 模型: `ckpt/onlypkt_ftwithrna_oncrossdocked_onlygeneralfeat_train_best_val_loss_step_111429.pth`（全程不改权重/采样；rdock 走 `rdock_protocol/` 规范）

## 分子 1: T1（花菁，实验筛出的 KRAS G4 配体）

**SMILES**
```
CCN1C=C/C(=C/C=C/c2cc[n+]3ccccc3n2)c2ccccc21
```
(另一写法: `c1ccc2/C(=C\C=C\c3cc[n+]4ccccc4n3)/C=CN(CC)c2c1`)

**结构**: 25 重原子，净电荷 +1
- 1-乙基-1,4-二氢喹啉(供体端，非芳香)
- 丁二烯共轭桥(C=C-C=C，4 原子链)
- 1,8-二氮萘鎍(萘啶鎍，阳离子中心)

**masked-probe 元素背书判定**(BER102 与 KPT102 两口袋一致)：

| 位点 | 目标元素 | 模型主张 | 概率 | 判定 |
|---|---|---|---|---|
| tgt18 吡啶型 N | N* | N* | **76.3% / 81.2%** | ✓ 模型强背书(保留) |
| tgt12 桥头鎍 | N⁺ | **C\*** | **98.7% / 98.2%** | ✗ 模型最坚决否决 |
| tgt2 喹啉 N | N | C\* | 9.1% / 7.1% | ✗ 否决(两口袋) |
| 位1 乙基末端 | C | O | 94.2% / 95.2% | ✗ 模型要甲氧基 |

**复现路径**: 20k 冷启动+inpainting 采样 0 命中，最高 Tanimoto 0.30（骨架级）。
**决定性障碍**: 桥头鎍位 98.7% 驳回 —— 13 类表征无电荷维度，模型对阳离子中心天然不可见；且 20k 采样双环芳香鎍零出现。
**最终判定: 精确复现不可达(合规路径下)**。

**方法论警告(重要)**: 该模型 13 类 = (元素， 芳香) 二元组, 无价态/电荷/键级约束。
发现 T1 桥区 3-4 位同时从 C 变 N 的"强背书分子" 是**组合伪影**：
- 逐位独立 argmax 拼装 → C=N-C=N-N=N 三氮烯链(化学荒谬，训练数据 0 先例)
- 链式条件 probe (顺序锁定) 验证 → 联合最优 C+O+N+N 拼装后价键非法(O 3 价)
- 结论: **模型在多原子连续区域(桥/链)上的元素组合不可作为化学结论**; 只对孤立单原子位点(环内/端基/单原子桥)的元素背书可信。
- 修正后的"模型倾向 T1 变体"(仅采信单原子位): `CO[C@H]1C=C/C(=C/C=C/c2ccc3ccccc3n2)c2ccccc21`

## 分子 2: T2（双苯并噻唑，BODIPY 前体类染料）

**SMILES**
```
c1ccc2sc(Cc3nc4ccccc4s3)nc2c1
```
(另一写法: `C1C2SC(CC3=NC4C=CC=CC=4S3)=NC=2C=CC=1`)

**结构**: 19 重原子，中性，2 个环硫
- 苯并噻唑 ×2(含噻唑环 S+2N)
- 亚甲基桥(-CH₂-, 1 原子, sp3)

**掩码探针全 19 位**: 0 个真实元素分歧(仅芳香 flag 差异)，**argmax 拼装 = t2 本身(Tc 1.000, 价键合法)**——模型在每个位点都同意目标元素。

**复现路径(两条均达成 SMILES == t2)**:

### 路径一: 概率背书替换直通(t2_repro, 高产 ~10%/百样本)
1. 解码表修复后发现模型会生成环 S(环 S 分子 4/82 = 4.9%; 旧"从不生成环硫"是 idx9-12 解码错位伪影)
2. t2 几何 masked probe: 两个 S 位 **P[S] = 84–97%**(三实验一致，前 5 pose 鲁棒)，全元素自洽度 94.0%
3. 种子 = 双苯并噻唑 C2···C2 = 2.46 Å(通用 CH₂ 插入距离区间 2.4–2.7 Å；共面; 未用 t2 构象)
4. sample_by_seed inpainting(19 原子锚, free=1 桥位) → **172 个 SMILES==t2 精确命中**

### 路径二: 纯从头合规路径(t2_denovo, t2 仅作判据)
```
① 冷启动 2000 采样 → 全氮等电子骨架(BM 0.375, phenanthroline 类)
② 单体 P[S] 全部失败(0/48 过 10% 门) → 发现 P[S] 由分子内上下文驱动
   位姿扫描 212 摆放(106/212 过门) → N→S 替换(背书 11-12%) → 双苯并噻唑
③ 种子 inpainting → NH-桥双苯并噻唑(Tc 0.517, 模型桥位偏好 N)
④ 桥位 P[C] probe(redock pose, 22.1% 过 10% 门) → N→C 替换
   → SMILES == t2 ✓
```

**双评分**(路径二产物):
| 工具 | 结果 | 参照 berberine |
|---|---|---|
| rdock(BER102 规范协议) | SCORE.INTER −42.92(−43.88 @KPT102 位) | −45.7(同量级) |
| rnasmol 6 版 ensemble | P=0.692, 4/6 gate | 0.595, 4/6(优) |
| pose 质心 vs 共晶位 | 0.11 Å(占位一致) | — |

**为什么 T2 可复现而 T1 不可**: T2 桥是单原子(CH₂), 元素判断全为孤立单原子位/环内位, 无组合谬误空间; T1 桥是 4 原子共轭链, 落入表征伪影区 + 该分子关键位点(桥头鎍)本身在模型先验外。**模型分布内的分子(每点都同意)可精确复现；分布外分子系统性驳回不可达**。

## 方法论沉淀(共 5 条)

1. 解码表必须与训练编码逐类对齐(featurizer idx9-12: 芳P/脂S/芳S/Cl; 修复前"模型不生成环硫"为伪影)
2. 元素替换合法性判据 = masked probe 条件分布(芳香感知信念; 姿态依赖 — 须在红ocked pose 下探测)
3. P[S] 由分子内上下文驱动(双稠环+桥), 单环姿态再好也不过门
4. 种子设计把生成难题转成模型众数行为(3锚闭环失败 → 单原子双锚插入 2.5Å)
5. probe 适用边界: 孤立单原子位(环内/端基/单原子桥)可信; 多原子连续区域(共轭桥/链)的元素组合为表征伪影, 不可作为化学结论

# mol2 复现流程文档(骨架级,合法)

> 通过**同骨架元素替换**(NH/O→S)获取 mol2 的苯并噻吩骨架。复现止于骨架级;
> 进一步精确化(替换受体/供体为绕丹宁/N(CCO)C)属人工分子编辑,不计入模型复现。

## 1. 摘要

mol2(`CN1C(=O)/C(=C/c2cc3ccc(N(C)CCO)cc3s2)SC1=S`)含 3 个硫原子(苯并噻吩 1S + 绕丹宁 2S),模型在 8HZK 口袋**不生成**这些含硫骨架。通过诊断发现:苯并噻吩在 1w 生成分子里有**等电子体**(吲哚/苯并呋喃,可 NH/O→S 替换)。
据此采用**元素替换取骨架**(合法后处理),获得**苯并噻吩骨架级复现**(取代模式与 mol2 同构,保留模型原有取代基)。

> **此前版本曾声称"原子级精确复现 Tc=1.0"**——基于 Step2/Step3 的嫁接
> (切除模型原有哌啶-OH + 接绕丹宁;切除异丙烯氨基 + 接 N(CCO)C),
> 已被判定为**不合法**(人工拼贴目标答案),已删除。详见 §6 合法性边界。

## 2. 目标分子

```
mol2: CN1C(=O)/C(=C/c2cc3ccc(N(C)CCO)cc3s2)SC1=S
```

| 结构单元 | 角色 | 含 S | 模型可及性 |
|---------|------|------|-----------|
| 苯并噻吩 `c2cc3ccc(...)cc3s2` | 共轭桥 | 1S | 不生成,但有等电子体(吲哚)→ 元素替换 |
| 绕丹宁 `C1(=O)N(C)C(=S)S` | 受体 | 2S | 不生成,无等电子体 → 仅靠人工编辑引入 |
| 亚甲基 `=C\` | 连接桥 | — | — |
| N(CCO)C | 供体 | — | 不生成 -CH2CH2OH → 仅靠人工编辑引入 |

## 3. 前置诊断(决定策略)

| 诊断项 | 结果 | 含义 |
|--------|------|------|
| 功能库含苯并噻吩/绕丹宁 | ✓ | 片段库覆盖目标骨架 |
| 1w 生成分子含苯并噻吩 | 0(直接) | 模型不生成 |
| 1w 生成分子含**吲哚/苯并呋喃**(等电子体) | **3+1=4 个** | **NH/O→S 替换可行(合法)** |
| 1w 生成分子含绕丹宁 | 0(无等电子体) | 无法靠合法后处理引入 |

**关键洞察**:苯并噻吩(6-5 稠合单杂原子环)的等电子体是吲哚(NH)和苯并呋喃(O)——把杂原子 N/O 换成 S 即得苯并噻吩。模型生成吲哚(3 个),故元素替换可获得苯并噻吩骨架。

## 4. 合法复现流程(止于 Step 1,骨架级)

### Step 1:元素替换获取苯并噻吩骨架(`step1_substitute_S.py`)

**输入**:`output/8hzk_output/dummy_ligand/dummy_ligand.sdf`(1w 限制原子数生成分子)
**逻辑**:
1. 定位含**吲哚**(`c1ccc2[nH]ccc2c1`)或**苯并呋喃**(`c1ccc2occc2c1`)的分子(共 4 个:idx 5133/7785/8700/9882)
2. 对杂原子(N 或 O)执行:`atom.SetAtomicNum(16)`(硫)、`SetNumExplicitHs(0)`、`SetIsAromatic(True)`
3. `SanitizeMol`(若 kekulize 失败,跳过 kekulize 后重新感知芳香性)
4. **保留分子的 3D 坐标**(苯并噻吩环继承自模型生成的口袋坐标,仅键长微调)
5. **保留模型原有的全部取代基**(哌啶-OH、异丙烯氨基等),不切除、不嫁接
6. 验证:替换后匹配苯并噻吩 SMARTS `c1ccc2sccc2c1`

**输出**:`step1_benzothiophene.sdf`(4 个苯并噻吩骨架分子,带口袋 3D + 模型原取代基)

**关键发现**:idx=5133 的苯并噻吩**取代模式与 mol2 完全同构**——供体位在苯环 SMARTS-pos 1,C2 取代位(噻吩环)在 SMARTS-pos 5。这使骨架对应 mol2 的拓扑结构。

### 🟢 合法复现终点(Step 1 输出)

```
C=C(C)Nc1ccc(-c2cc3ccc(N4CCC[C@@H](O)C4)cc3s2)cc1     [step1_benzothiophene #0, idx5133]
```
- 苯并噻吩骨架(1S,NH→S 元素替换)
- 取代模式同构于 mol2(供体位/受体位对应)
- 取代基为模型原产物自带(哌啶-OH、异丙烯氨基),保留

**模型 + 合法后处理的复现边界至此。**

## 6. 合法性边界(关键说明)

**此前版本曾声称"mol2 原子级精确复现 Tc=1.0"——基于嫁接,不合法,已删除。**

嫁接 = 切除模型生成的原有取代基 + 接目标基团,具体包括:
- 旧 Step2:切除 4-异丙烯氨基苯基 → 接 FluoDB 绕丹宁
- 旧 Step3:切除哌啶-OH → 接 N(CCO)C

**无论 FluoDB 引入是否合规(边界 a)**,只要操作是"切除模型原有 + 接目标基团",
都属嫁接,不构成模型复现能力。复现标准重新界定为**骨架级相近**。

**合法 vs 不合法对照**:

| 操作 | 合法性 | 说明 |
|------|--------|------|
| 元素替换(NH→S,同骨架等电子体) | ✅ | 保留模型生成的拓扑与 3D,不切除取代基 |
| 对接引导(smina) | ✅ | 引入 3D 上下文,不改分子结构 |
| 保留模型原有取代基 | ✅ | 不切除模型生成的侧链 |
| **嫁接(切除+接目标基团)** | ❌ | 人工拼贴目标答案 |

依赖嫁接的脚本与产物已归档至 `casestudy/8hzk/_deprecated_graft/`(含 README)。

## 7. 关键设计决策(更新)

1. **元素替换优先于对接引入**:苯并噻吩有等电子体(吲哚/苯并呋喃),元素替换比从 FluoDB 对接引入整个桥**保留了模型生成的口袋 3D 坐标**(更贴合口袋),且操作轻量、合法。这是用户"同骨架替换元素"诊断的直接落地。
2. **idx5133 的同构性**:并非所有 4 个苯并噻吩骨架都能用——只有 idx5133 的取代模式与 mol2 同构(供体位/受体位对应)。这是筛选候选的关键标准。
3. **保留模型原有取代基**:元素替换只改杂原子(NH→S),不切除模型生成的任何取代基(哌啶-OH、异丙烯氨基)。这保证操作合法——产物仍是"模型 + 元素替换",不是"嫁接目标答案"。
4. ~~绕丹宁必须 FluoDB 引入~~:**绕丹宁的引入(切除+接)属嫁接,已删除**。模型无法靠合法后处理生成绕丹宁(无等电子体),这是 mol2 复现止于骨架级的根本原因。
5. ~~RWMol 真实手术~~:**嫁接手术(Step2)已删除**。RWMol 原子级编辑本身是中性工具,但用于"切除模型原有 + 接目标基团"时不合法。

## 9. 方法论洞察:与 mol4 复现的对比(合法部分)

| 维度 | mol4(二苯乙烯,无S) | mol2(苯并噻吩,含S) |
|------|------|------|
| 桥的可及性 | 模型限制原子数后能生成(stilbene) | 模型完全不生成,但有等电子体(吲哚) |
| 主策略 | 限制原子数 + 对接 CCN + 固定骨架迭代 | **元素替换**(NH→S) |
| 合法终点 | Tc=0.58(迭代产物,Murcko==mol4) | 苯并噻吩骨架(取代模式同构 mol2) |
| 受体来源 | 对接引入(C=C(C#N),3D 种子,合法) | 无合法来源(绕丹宁不生成,嫁接已删除) |
| 供体来源 | 模型生成(芳胺 NH2,保留) | 模型生成(异丙烯氨基,保留) |
| 3D 来源 | 模型生成(迭代) | 元素替换继承模型坐标 |

**通用规律(合法部分)**:
- **有等电子体的骨架**(苯并噻吩←吲哚/苯并呋喃)→ 元素替换(快,保留口袋 3D,合法)
- **能生成的骨架**(二苯乙烯)→ 限制原子数 + 迭代(合法)
- **都不行的部分**(绕丹宁、C=C(C#N) 整分子、噻吩并噻吩)→ 骨架级相近无法靠合法后处理精确化
- ~~N(CCO)C 供体嫁接(通用)~~ → **不合法,已删除**

## 10. 适用边界

- 元素替换要求生成分子里有等电子体(吲哚/苯并呋喃等)。若等电子体也 0(如 mol1/3 的噻吩并噻吩),此法不适用,只能做骨架级相近(对接引入整个桥也属合法,但仍止于骨架级)。
- 元素替换/对接属后处理分子工程,不改模型权重/checkpoint。
- **嫁接(切除模型原有取代基 + 接目标基团)不合法**,不计入模型复现能力。
  所有依赖嫁接的脚本与产物已归档至 `casestudy/8hzk/_deprecated_graft/`。

# 8HZK 荧光分子生成 — 完整轨迹

> 从"模型完全不生成目标分子核心特征"到"骨架级复现 2 个 known_mols"的完整演进路径。记录每个阶段的尝试、发现、突破与决策。
>
> **复现标准(本版重新界定)**:复现止于**骨架级相近**(Murcko 相同/高 Tc)。
> 此前依赖嫁接(切除模型原有取代基 + 接上目标基团)获得的"原子级精确 Tc=1.0"
> 被判定为**不合法**(人工拼贴目标答案),已从所有复现路径删除。

## 0. 起点

```
输入:  8HZK RNA 口袋(344 原子) + 4 个 known_mols(实验验证荧光分子)
模型:  BFN (onlypkt_ftwithrna_oncrossdocked checkpoint)
约束:  不改模型权重/采样网络,只做后处理
目标:  复现 known_mols 中至少一个(骨架级)
```

**4 个 known_mols**:
- mol1: 绕丹宁 + **噻吩并噻吩**(2S稠环) + N(CCO)C
- mol2: 绕丹宁 + **苯并噻吩**(1S) + N(CCO)C
- mol3: 香豆素 + **噻吩并噻吩**(2S) + N(CCO)C
- mol4: C=C(C#N) + **二苯乙烯**(无S) + N(CCO)C

共同点:都是 D-π-A 推拉电子染料,供体都是 N(CCO)C。

## 1. 轨迹总览(阶段化)

```
阶段A 尝试直接生成 + 后处理引导        ──→ 撞墙:模型分布边界
   SPEC01 BRICS库  SPEC02 sumlogp  SPEC03 种子循环  SPEC04 功能库  SPEC05 pipeline
   发现: 模型完全不生成 C=C(C#N)/噻吩/绕丹宁 (0/3526)。后处理改变不了分布。
         │
         ▼ 关键转折
阶段B 限制原子数 + 外部引入              ──→ 突破:缺失特征出现
   SPEC06 限制原子数(20-28) + FluoDB对接引入C=C(C#N)
   发现: C=C(C#N) 从0→20,stilbene 4→28。骨架级复现(Tc 0.33)。
         │
         ▼ 精确化
阶段C 固定骨架迭代                       ──→ mol4 骨架级复现(合法终点)
   SPEC07 固定骨架迭代
   结果: mol4 骨架级复现(Tc=0.58, Murcko 骨架==mol4, 16个),带模型生成的芳胺 NH2。
         (此前由"嫁接 N(CCO)C"获得 Tc=1.0 的部分已删除 — 不合法)
         │
         ▼ 方法论迁移
阶段D 元素替换取骨架                     ──→ mol2 骨架级复现(合法终点)
   诊断: 苯并噻吩有等电子体(吲哚/苯并呋喃)
   执行: NH/O→S元素替换
   结果: mol2 苯并噻吩骨架级复现(元素替换,带模型原有哌啶-OH/异丙烯氨基)。
         (此前由"嫁接绕丹宁+N(CCO)C"获得 Tc=1.0 的部分已删除 — 不合法)
```

### 1.1 关于"嫁接"为何不合法(关键说明)

**嫁接** = 切除模型生成的原有取代基 + 接上目标基团(N(CCO)C、绕丹宁等),
目的是把模型产物"修正"到与 known_mol 完全一致的 SMILES。

这相当于**人工拼贴目标答案**,而非模型生成 + 合法后处理。无论嫁接脚本多么精巧,
它都没有改变"切除原有 + 接上目标"这一本质,因此:
- 不能算作模型的复现能力;
- 不能声称"Tc=1.0 精确复现";
- 必须从所有复现路径删除。

**合法后处理的边界**(保留):
- 元素替换(同骨架等电子体替换,如 NH→S)
- 对接引导(smina 引入 3D 上下文,不改结构)
- 固定骨架迭代(模型自身在约束下补全)
- 保留模型原有取代基(不切除模型生成的侧链)

所有依赖嫁接的文件已归档到 `casestudy/8hzk/_deprecated_graft/`,详见该目录 README。

## 2. 阶段A:撞墙——发现模型的生成分布边界(SPEC 01-05)

### 2.1 尝试的路径
| SPEC | 方法 | 做了什么 |
|------|------|---------|
| 01 | BRICS 构件库 | 从 FluoDB 切 1853 个构件 + 药效团签名 |
| 02 | 概率引导(sumlogp) | 保留模型概率矩阵,用 sumlogp 排序种子+替换 |
| 03 | 频率筛选+种子循环 | freq≥50 聚焦到 69 构件,种子循环迭代 |
| 04 | **功能库 D/A/π(非BRICS)** | 共轭分区+功能锚定,产出完整功能单元(stilbene不被切碎) |
| 05 | 功能库pipeline | 匹配回收+种子生成复现 mol4 |

### 2.2 撞墙的核心发现
**模型在 8HZK 口袋的生成分布系统性缺失 known_mols 的核心特征**:
```
3526 个生成分子中:
  C=C(C#N) 氰基乙烯(mol4受体)  = 0   ← 真零,不是低频
  噻吩(mol1/2/3桥组件)        = 0   ← S芳香环不生成
  绕丹宁(mol1/2受体)          = 0
  stilbene 与 C#N 互斥(不共存)
```
**纯生成+后处理改变不了模型的生成分布**——这是 SPEC 01-05 全部撞墙的根因。功能库再好、sumlogp 再精,都只能在模型"已经生成"的产物上操作。

### 2.3 阶段A的价值
- 沉淀了**功能库方法论**(SPEC04,完整功能单元提取,替代BRICS)
- 沉淀了**概率引导**(sumlogp,模型似然评分)
- 清晰界定了**后处理的边界**——为阶段B的突破指明方向:必须从外部引入缺失结构

## 3. 阶段B:突破——限制原子数 + 外部引入(SPEC 06)

### 3.1 关键转折#1:限制原子数
**发现**:known_mols 是 22-27 重原子,但模型默认按口袋体积采样生成 30-40+ 原子的大分子。
**改动**:`dataloader/featurizer.py` 的 `GeomSeedMolOnlyPocket` 冷启动分支 `total_n = random.randint(20,28)`。
**效果**:
```
达标速度: 45/70轮(大分子,卡住) → 7593/78轮(小分子,无停滞)  [170倍提速]
C=C(C#N): 0 → 20 个      ← mol4 受体特征出现了!
stilbene: 4 → 28 个      ← mol4 桥
D+A+π齐全: 16 → 29 个
```
**洞察**:限制原子数聚焦了化学空间,让模型触及 known_mols 大小区域,之前缺失的特征"自然出现"。这是被低估的强先验。

### 3.2 关键转折#2:对接引入模型不生成的结构
模型仍不生成某些结构(纯 C=C(C#N) 在整分子里仍稀少)。解法:
```
FluoDB 取 C=C(C#N) 片段(氰基丙烯酸,freq 3288)
  → smina 对接到 8HZK 口袋(util/smina.static)
  → 获得口袋上下文 3D(解决"孤立3D不能做种子"的问题)
  → 作为 sample_by_seed 种子,模型在其上补全
```
**产物**:`ccn_seeds_docked.sdf`(5 个口袋 3D 的 C=C(C#N) 种子)。

### 3.3 阶段B结果
骨架级复现 mol4:**Tc 0.33**,12 个产物含 mol4 核心(氰基二苯乙烯)。从"完全不可能"到"骨架出现"。但产物有多余装饰(甲氧基/羟基),供体不准(N(CCO)C→N(C)C)。

## 4. 阶段C:mol4 骨架级复现——固定骨架迭代(SPEC 07,合法终点)

### 4.1 关键转折#3:固定骨架迭代压缩装饰
**问题**:产物含 mol4 骨架,但模型加了多余装饰。
**解法**:
```
提取产物的 mol4 骨架(氰基二苯乙烯+胺,SMARTS定位,保留口袋3D)
  → fixed_atom_mask 固定骨架原子
  → total_n 严格限制 25-27(接近mol4的27)
  → sample_by_seed:模型只能补 5-10 个非骨架原子(装饰空间大减)
  → 迭代 3-5 轮
```
**效果**:Tc 0.33 → **0.58**,16 个 Murcko 骨架==mol4。

### 4.2 mol4 复现合法终点(重新界定)
**复现终点**:迭代产物
```
N#CC(=Cc1cccc(N)c1)c1ccc(-c2ccccc2)cc1
```
- **Tc=0.58**(ECFP4 vs mol4)
- **Murcko 骨架 == mol4**(16 个产物骨架精确相同)
- 供体为**模型生成的芳胺 NH2**(保留,不切除)
- 联苯扩展(桥的两侧苯环齐备),D-π-A 体系完整

**此前版本曾声称 Tc=1.0**(靠嫁接 NH2→N(CCO)C,见旧版 §4.2),已被判定
**不合法**(人工拼贴目标答案,切除模型原有 NH2 + 接目标 N(CCO)C)。
该嫁接脚本与产物已归档至 `casestudy/8hzk/_deprecated_graft/`。

> **明确边界**:NH2 → N(CCO)C 这一步属**人工分子编辑**(把模型生成的供体
> 替换为已知目标供体),不计入模型复现能力。模型 + 合法后处理止于上述迭代产物。

### 4.3 mol4 复现完整路径(合法部分)
```
模型不生成C=C(C#N) (0/3526)
  → 限制原子数(20-28)            [SPEC06]  C=C(C#N)出现(20个)
  → 对接CCN+固定骨架迭代          [SPEC07]  Tc 0.58, 16个Murcko同  ✅ 骨架级复现(合法终点)
```
> 后续 NH2 → N(CCO)C 嫁接(原 §4.3 末行)已删除,属人工分子编辑,不计入复现。

## 5. 阶段D:mol2 骨架级复现——元素替换取骨架(合法终点)

### 5.1 诊断(决定策略)
对三个含硫分子(mol1/2/3)做两点诊断:
```
诊断1: 功能库含硫片段?           → ✓ 噻吩/苯并噻吩/绕丹宁都在
诊断2: 生成分子含目标骨架?       → 直接含S极少;但等电子体?
  mol2 苯并噻吩的等电子体:吲哚3 + 苯并呋喃1 = 4个  ← NH/O→S可替换!
  mol1/3 噻吩并噻吩的等电子体:联呋喃0,联吡咯0      ← 无,元素替换无效
  绕丹宁的等电子体:hydantoin 0                      ← 无,需FluoDB引入
```

### 5.2 关键转折#4:同骨架元素替换
mol2 的桥(苯并噻吩)有等电子体(吲哚/苯并呋喃)。**用户的"同骨架替换元素"诊断**指明路径:
```
生成分子的吲哚(NH) / 苯并呋喃(O)
  → atom.SetAtomicNum(16) 把杂原子换成 S    [元素替换,合法]
  → 保留口袋3D坐标(苯并噻吩环继承模型生成的坐标)
  → 得到苯并噻吩骨架
```
**关键**:idx5133 的苯并噻吩**取代模式与 mol2 同构**(供体位/受体位对应)。
**保留模型原有的取代基**(哌啶-OH、异丙烯氨基),不切除、不嫁接。

### 5.3 mol2 复现合法终点(重新界定)
**复现终点**:元素替换苯并噻吩骨架
```
C=C(C)Nc1ccc(-c2cc3ccc(N4CCC[C@@H](O)C4)cc3s2)cc1
```
- **苯并噻吩骨架**(1S,经 NH→S 元素替换得到)
- 取代基为**模型原产物自带**(异丙烯氨基、哌啶-OH),保留不切除
- 取代模式与 mol2 同构(供体位/受体位对应)

**此前版本曾声称 Tc=1.0**(靠 Step2 嫁接绕丹宁 + Step3 嫁接 N(CCO)C),
已被判定**不合法**(切除模型原有哌啶/异丙烯氨基 + 接目标基团)。
该嫁接脚本(`step2_assemble_mol2.py`)与产物(`mol2_assembled.sdf`、
`mol2_docked.sdf`、`mol2_reproduction_report.pdf`)已归档至
`casestudy/8hzk/_deprecated_graft/`。

> **明确边界**:把模型原有的哌啶-OH 换成绕丹宁、把异丙烯氨基换成 N(CCO)C
> 属**人工分子编辑**(用目标基团替换模型生成基团),不计入模型复现能力。
> 模型 + 合法后处理止于元素替换后的苯并噻吩骨架。

### 5.4 mol2 复现完整路径(合法部分)
```
dummy_ligand #5133(吲哚分子)
  → 元素替换 NH→S  [step1]  苯并噻吩骨架(取代模式同构 mol2)  ✅ 骨架级复现(合法终点)
```
> 后续嫁接绕丹宁 + 嫁接 N(CCO)C(原 §5.3 Step2/Step3)已删除,属人工分子编辑,不计入复现。

## 7. 方法论沉淀:合法策略的三条通用规律

针对目标结构的**可及性**,选择不同策略(**仅限合法操作**):

```
目标结构在模型分布里?
├─ 能生成(限制原子数后) ──→ 限制原子数 + 固定骨架迭代
│                             案例: mol4 二苯乙烯(骨架级 Tc=0.58)
│
├─ 不生成,但有等电子体 ──→ 同骨架元素替换(NH/O→S)
│   (生成分子有O/N类似物)     案例: mol2 苯并噻吩 ← 吲哚/苯并呋喃
│
└─ 不生成,也无等电子体 ──→ 仅能做骨架级相近,无法靠合法后处理精确化
                            案例: 绕丹宁、C=C(C#N)整分子、噻吩并噻吩

> 注:若目标结构既不生成也无等电子体,进一步精确化只能靠人工分子编辑
> (切除+嫁接目标基团),这属于不合法操作,不计入模型复现能力。
```

## 8. 当前成果与剩余(骨架级复现)

| 分子 | 桥(可及性) | 合法策略 | 合法终点 |
|------|-----------|----------|----------|
| **mol4** | 二苯乙烯(能生成) | 限制原子数 + 固定骨架迭代 | ✅ **骨架级 Tc=0.58**(Murcko == mol4,16 个) |
| **mol2** | 苯并噻吩(有等电子体) | 元素替换 NH→S | ✅ **苯并噻吩骨架级复现**(取代模式同构 mol2) |
| mol1 | 噻吩并噻吩(无等电子体) | 仅能 FluoDB 对接引入整个桥 | 待攻 |
| mol3 | 噻吩并噻吩(无等电子体) | 同上,香豆素受体(无S,较易) | 待攻 |

**已骨架级复现 2/4 known_mols**(mol4 无S路径 + mol2 含S路径),覆盖了两种核心合法方法论(生成迭代 + 元素替换)。

剩余 mol1/mol3 的噻吩并噻吩桥无等电子体,只能走 FluoDB 对接引入(且仍止于骨架级,精确化需人工编辑)。

### 8.1 关于"精确复现"的明确边界说明

此前的版本曾声称 mol4/mol2 "原子级精确复现(Tc=1.0)",那是基于**嫁接**
(切除模型原有取代基 + 接目标基团)得到的,**不合法**。本版重新界定:
- **模型 + 合法后处理的复现边界** = 骨架级相近(Murcko 相同/高 Tc)
- **从骨架到精确 known_mol 的最后一步**(供体替换、绕丹宁引入)属**人工分子编辑**,
  不计入模型复现能力,文档中明确标注为"人工后续编辑"。

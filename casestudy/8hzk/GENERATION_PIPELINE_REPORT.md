# 8HZK 荧光分子生成流程报告

> 基于 BFN 模型 (`onlypkt_ftwithrna_oncrossdocked_onlygeneralfeat`) 对 8HZK RNA 口袋生成荧光分子的完整流程记录。约束:不改模型权重/采样网络,只做后处理。
>
> **复现标准**:止于**骨架级相近**(Murcko 相同/高 Tc)。此前依赖嫁接获得的
> 原子级精确复现已被判定为**不合法**(详见 §6 合法性边界)。

## 1. 摘要

从"模型完全不生成目标荧光分子核心特征"的困境出发,通过 **限制原子数 + FluoDB 功能库 + 对接引入缺失受体 + 固定骨架迭代** 的组合策略,实现了 known_mol (mol4) 的骨架级复现:**Tanimoto 0.580,16 个产物 Murcko 骨架与 mol4 相同**,D-π-A 药效体系完整。mol2 通过**元素替换(NH→S)**获得苯并噻吩骨架(取代模式同构 mol2)。本报告记录方法论演进、核心发现、可复用 pipeline、合法性边界,并给出通用化方向。

## 2. 目标与约束

- **靶点**:8HZK 纯 RNA 口袋(A/G/C/U 核苷酸,344 原子)
- **目标**:生成结合口袋的荧光分子,复现 `known_mols.txt` 中至少一个分子(**骨架级**)
- **约束**:不改 checkpoint / 采样网络 / 权重;只做生成后处理
- **核心 checkpoint**:`ckpt/onlypkt_ftwithrna_oncrossdocked_onlygeneralfeat_train_best_val_loss_step_111429.pth`

## 3. 方法论演进(SPEC 01-07)

| SPEC | 方法 | 结果 | 关键洞察 |
|------|------|------|---------|
| 01 | BRICS 构件库 + 药效团签名 | 库建成(1853 构件) | BRICS 会**切碎功能单元**(stilbene 的 C=C 被切→片段池 0) |
| 02 | 概率引导(sumlogp 排序+替换) | 药效团级引导 | 模型丢弃概率矩阵;需保留 P;sumlogp 可评分 |
| 03 | 频率筛选 + 种子循环 | 受阻(bug) | 种子循环从未真正跑过;freq≥50 保留 69 构件覆盖 known_mols |
| 04 | **功能库 D/A/π(非 BRICS)** | 三库建成(D2103/A105/π17) | 共轭分区+功能锚定,产出**完整功能单元**(stilbene 完整) |
| 05 | 功能库匹配回收 + 种子生成 | **C=C(C#N)=0** | 模型在 8HZK 分布里**不生成** mol4 受体特征 |
| 06 | **限制原子数 + 对接突破** | C=C(C#N) 出现(20个),骨架级复现(Tc 0.33) | 限制到 20-28 原子聚焦化学空间;对接引入模型不生成的片段 |
| 07 | **固定骨架迭代** | **Tc 0.580,16 个 Murcko 相同** | 固定骨架压缩装饰空间,迭代逼近(mol4 合法终点) |

## 4. 核心技术发现

### 发现 1:模型的生成分布边界
BFN 在 8HZK 口袋的生成分布**系统性缺失** known_mols 的核心特征:
- C=C(C#N) 氰基乙烯:0/3526(大分子生成)
- 噻吩/绕丹宁:0(含 S 芳香环)
- stilbene 与 C#N 互斥(不共存)

**纯生成+后处理改变不了分布**——这是 SPEC 01-05 撞墙的根因。

### 发现 2:限制原子数是关键转折
known_mols 是 22-27 重原子。模型默认按口袋体积采样生成偏大分子(30-40+原子)。
将 `total_n` 限制到 `random.randint(20,28)`(`dataloader/featurizer.py:632`)后:
- 达标速度提升 ~170 倍(45/70 轮 → 7593/78 轮)
- **C=C(C#N) 从 0 变 20**,stilbene 从 4 变 28
- 化学空间聚焦到 known_mols 大小,触及了之前缺失的特征区域

### 发现 3:对接引入模型不生成的结构
模型不生成 C=C(C#N),但 FluoDB 里有大量(freq 3288)。解法:
- 从 FluoDB 取 C=C(C#N) 片段(氰基丙烯酸等)
- 用 `util/smina.static` **对接到 8HZK 口袋**(`casestudy/8hzk/ccn_seeds_docked.sdf`)
- 获得口袋上下文 3D(解决"孤立 3D 不能做种子"的问题)
- 作为 `sample_by_seed` 种子,模型在其上补全

### 发现 4:固定骨架迭代压缩装饰
含骨架产物有多余装饰(甲氧基/羟基/哌啶)。解法:
- 提取产物的 mol4 骨架(氰基二苯乙烯+胺,SMARTS 定位,保留口袋 3D)
- `fixed_atom_mask` 固定骨架,`total_n=25-27`
- 模型只补 5-10 个非骨架原子(装饰空间大减)
- 迭代 3-5 轮,Tanimoto 0.33→0.58

### 发现 5:同骨架元素替换取含硫骨架(mol2)
mol2 的苯并噻吩模型不生成,但有等电子体(吲哚/苯并呋喃)。把杂原子 N/O 换成 S
(`atom.SetAtomicNum(16)`),保留模型生成的口袋 3D,即得苯并噻吩骨架。
取代模式与 mol2 同构,取代基保留模型原产物自带(不切除)。

## 5. 可复用 Pipeline(完整流程,仅含合法操作)

```
8HZK_pocket.pdb
    │
    ▼ ① 限制原子数生成(冷启动,total_n=randint(20,28),seed_used=False)
    │   产出 ~1w 原始分子(output/.../iter_*/raw_output/)
    │
    ▼ ② FluoDB 功能库匹配回收(D/A/π 三库,SMARTS 匹配)
    │   识别每个分子的完整功能单元(带口袋 3D)
    │   统计覆盖,回收含 D/A/π 的片段
    │
    ▼ ③ 对接补充缺失受体(smina,可选)
    │   FluoDB 片段 → 对接口袋 → 口袋 3D 种子
    │   (用于引入模型不生成的受体,如 C=C(C#N))
    │
    ▼ ④ 种子构造(回收片段 + 对接种子)
    │   含 D+A+π 的分子做种子,或组合
    │
    ▼ ⑤ sample_by_seed 生成(固定功能单元原子)
    │   模型补全剩余,产物含目标骨架
    │
    ▼ ⑥ 固定骨架迭代(可选,追求骨架级相近)
    │   提取产物骨架 → 固定 → 再生成 → 迭代逼近
    │
    ▼ ⑦ 同骨架元素替换(可选,含硫目标且有等电子体时)
    │   生成分子含吲哚/苯并呋喃 → NH/O→S → 含硫骨架
    │
    ▼ ⑧ 筛选(Tanimoto + 子结构 + Murcko + affinity)
    骨架级复现产物(合法终点)
```

> **明确边界**:流程止于骨架级复现。从骨架到精确 known_mol 的最后一步
> (供体替换、绕丹宁引入等)若涉及"切除模型原有取代基 + 接目标基团"(嫁接),
> 属**人工分子编辑**,不计入模型复现能力。

## 6. 复现成果(骨架级)

### 6.1 mol4 骨架级复现

| 指标 | 值 |
|------|-----|
| 最高 Tanimoto vs mol4 | **0.580** |
| Tanimoto > 0.5 | 2 个 |
| Murcko 骨架 == mol4 | **16 个** |
| D-π-A 功能体系 | 完整(氰基二苯乙烯+联苯+胺供体) |
| 原子数 | 平均 25.9(mol4 为 27) |

**top-1 产物(合法终点)**:`N#CC(=Cc1cccc(N)c1)c1ccc(-c2ccccc2)cc1`
(Tc=0.580,Murcko 与 mol4 相同,供体为模型生成的芳胺 NH2)。

### 6.2 mol2 骨架级复现

| 指标 | 值 |
|------|-----|
| 苯并噻吩骨架 | ✓(NH→S 元素替换得到) |
| 取代模式 | 同构于 mol2(供体位/受体位对应) |
| 取代基 | 保留模型原产物自带(哌啶-OH、异丙烯氨基) |
| 来源 | `step1_benzothiophene.sdf`(4 个骨架) |

**合法终点**:`C=C(C)Nc1ccc(-c2cc3ccc(N4CCC[C@@H](O)C4)cc3s2)cc1`

### 6.3 合法性边界(关键说明)

**此前版本曾声称 mol4/mol2 "原子级精确复现 Tc=1.0"——基于嫁接,不合法,已删除。**

嫁接 = 切除模型生成的原有取代基 + 接目标基团(N(CCO)C / 绕丹宁等),相当于
**人工拼贴目标答案**。具体包括:
- mol4 旧 Step4:切除芳胺 NH2 → 接目标 N(CCO)C
- mol2 旧 Step2:切除 4-异丙烯氨基苯基 → 接目标绕丹宁
- mol2 旧 Step3:切除哌啶-OH → 接目标 N(CCO)C

**无论脚本多么精巧,本质都是"切除模型原有 + 接上目标"**:
- 不能算作模型的复现能力;
- 不能声称 Tc=1.0 精确复现;
- 必须从所有复现路径删除。

依赖嫁接的脚本与产物已归档至 `casestudy/8hzk/_deprecated_graft/`(含 README)。

**合法后处理的边界**(保留):
- 元素替换(同骨架等电子体替换,如 NH→S)
- 对接引导(smina 引入 3D 上下文,不改结构)
- 固定骨架迭代(模型自身在约束下补全)
- 保留模型原有取代基(不切除模型生成的侧链)

**复现标准重新界定**:模型 + 合法后处理的复现边界 = **骨架级相近**
(Murcko 相同 / 高 Tc)。从骨架到精确 known_mol 的最后一步属人工分子编辑,
不计入模型复现能力。

## 8. 通用化方向(降低针对性)

当前流程高度针对 mol4。降低针对性以生成**更多样荧光分子**:
- 用**通用 D/A/π 功能库**(覆盖各种荧光染料家族,非 mol4 特定)
- 不固定特定骨架,让 D/A/π 自由组合(各种供体+受体+桥)
- 限制原子数 20-28(类药范围)
- 生成 → 匹配回收 → 多样种子 → sample_by_seed
- 目标:大量 D/A/π 齐全的、骨架多样的荧光分子

## 9. 经验总结

1. **后处理的边界**:纯后处理改变不了模型生成分布。要引入模型不生成的结构,必须借助外部数据(FluoDB)+ 对接(获 3D)。但**引入 3D 种子 ≠ 切除+嫁接目标基团**——前者合法,后者不合法。
2. **原子数限制是被低估的强先验**:聚焦化学空间比任何评分都有效。
3. **功能库 > BRICS**:基于化学规则的功能单元提取,优于机械切分。
4. **迭代的力量**:固定骨架+迭代,是压缩模型装饰偏好的有效手段。
5. **元素替换是含硫骨架的合法出路**:当目标骨架(苯并噻吩)模型不生成但有等电子体(吲哚/苯并呋喃)时,NH/O→S 元素替换保留模型生成的拓扑与 3D,属合法后处理。
6. **嫁接的诱惑与陷阱**:把模型产物"修正"到与 known_mol 完全一致很诱人,但属人工拼贴,必须从复现路径删除。复现止于骨架级。

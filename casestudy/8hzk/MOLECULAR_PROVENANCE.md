## mol4 分子链(合法终点 = 节点 5,迭代产物 Tc=0.58)

mol4 = `CN(CCO)c1cccc(/C=C(\C#N)c2ccc(-c3ccccc3)cc2)c1`(目标参考,仅作 Tc 对照基准)

### 起点汇聚(两个来源)

**来源 A — 外部对接的 C=C(C#N) 受体种子**(模型不生成,从 FluoDB 对接引入):
```
C/C=C(\C#N)C(=O)O        氰基丙烯酸(FluoDB row)
  → smina 对接到 8HZK 口袋(ccn_seeds_docked.sdf)
  → 获得口袋 3D                          Tc=0.154
```

**来源 B — 模型生成的含 stilbene+胺 分子**(限制原子数 20-28 后,模型在 known_mols 化学空间生成):
```
CCC(=O)Nc1cccc(/C=C/c2ccccc2-c2ccc(O)[n+](C)c2)c1    dummy_ligand.sdf 中一个
  (含二苯乙烯桥 + 胺供体)                            Tc=0.208
```

### Step 1:sample_by_seed 组合生成(对接 CCN 种子 + 模型补全)
固定来源 A 的 C=C(C#N) 原子,模型在其周围补全(借鉴来源 B 的桥/供体模式):
```
→ CN(C)c1ccc(-c2ccc(C(C#N)=Cc3ccc(C(N)O)cc3N3CCCCC3)cc2)cc1     [mol4_skeleton_hits #0]
  含: 氰基二苯乙烯 C(C#N)=Cc... + 联苯 -c2ccc(...)cc2 + 胺      Tc=0.329
```
**首次出现 mol4 的 D-π-A 核心骨架**(氰基二苯乙烯),但带多余装饰(哌啶/羟胺)。

### Step 2:提取骨架(切割装饰)
从 Step1 产物中,用 SMARTS 定位 mol4 骨架原子(氰基二苯乙烯+胺),**切割掉装饰**(哌啶/羟基),保留核心骨架 + 口袋 3D:
```
→ N#CC(=Cc1cccc(N)c1)c1ccccc1    [spec07 seeds_round0]
  纯氰基二苯乙烯 + 芳胺(NH2)骨架                       Tc=0.471
```

### Step 3:固定骨架迭代(model 补全,压缩装饰)
固定 Step2 骨架原子(`fixed_atom_mask`),`total_n=25-27`,sample_by_seed 迭代 3-5 轮:
```
→ N#CC(=Cc1cccc(N)c1)c1ccc(-c2ccccc2)cc1    [迭代产物,联苯扩展]
  氰基二苯乙烯 + 联苯 + 芳胺(NH2)             Tc=0.580
```
**Murcko 骨架 == mol4**(骨架精确复现),供体为模型生成的芳胺 NH2。

### 🟢 合法终点(节点 5):骨架级复现 mol4
```
N#CC(=Cc1cccc(N)c1)c1ccc(-c2ccccc2)cc1
  Tc=0.58 · Murcko == mol4 · 16 个产物骨架相同
```
**模型 + 合法后处理的复现边界至此。**

> ❌ **原 Step 4(嫁接 NH2→N(CCO)C)已删除——不合法**:
> 把模型生成的芳胺 NH2 替换为已知目标供体 N(CCO)C,属**人工分子编辑**
> (切除模型原有取代基 + 接目标基团)。该步产物此前曾被声称 Tc=1.0,
> 但不构成模型的复现能力。脚本 `graft_donor.py` 与产物 `mol4_grafted.sdf`
> 已归档至 `casestudy/8hzk/_deprecated_graft/`。

### mol4 完整链(合法部分)
```
FluoDB C=C(C#N) ──对接──┐
                         ├─sample_by_seed──→ 含骨架产物(Tc0.33)
dummy_ligand stilbene ──┘                      │
                                        切割装饰 ↓
                                  纯骨架(Tc0.47)
                                        │
                                  固定迭代 ↓
                                  骨架+NH2(Tc0.58, Murcko==mol4)  🟢 合法终点
                                        │
                            嫁接 NH2→N(CCO)C ❌ 不合法(已删除)
                                  mol4(Tc1.0) ✗ 不计入复现
```
**说明**:模型复现边界至节点 5(迭代产物 Tc=0.58);进一步把 NH2 替换为 N(CCO)C
属人工分子编辑,不计入模型复现能力。

## mol2 分子链(合法终点 = 节点 2,元素替换苯并噻吩骨架)

mol2 = `CN1C(=O)/C(=C/c2cc3ccc(N(C)CCO)cc3s2)SC1=S`(目标参考,仅作对照基准)

### 起点:模型生成的含吲哚分子
```
C=C(C)Nc1ccc(-c2cc3ccc(N4CCC[C@@H](O)C4)cc3[nH]2)cc1     dummy_ligand.sdf #5133
  (含吲哚 [nH] —— 苯并噻吩的等电子体;模型在限制原子数后生成)
                                                          Tc=0.149(整体不像mol2,但骨架可改造)
```

### Step 1:元素替换 NH→S(获取苯并噻吩骨架)
把吲哚的杂原子 N 换成 S(`atom.SetAtomicNum(16)`),保留 3D:
```
替换: c3[nH]2 的 NH → c3[s]2   (保留模型原有的所有取代基,不切除)
→ C=C(C)Nc1ccc(-c2cc3ccc(N4CCC[C@@H](O)C4)cc3s2)cc1     [step1_benzothiophene #0]
  苯并噻吩骨架(取代模式与 mol2 同构)                      含 1S
```
**关键**:idx5133 的苯并噻吩取代模式与 mol2 同构(供体位/受体位对应)。
**保留模型原有的全部取代基**(异丙烯氨基、哌啶-OH),不切除、不嫁接。

### 🟢 合法终点(节点 2):苯并噻吩骨架级复现
```
C=C(C)Nc1ccc(-c2cc3ccc(N4CCC[C@@H](O)C4)cc3s2)cc1
  · 苯并噻吩骨架(1S,NH→S 元素替换)
  · 取代模式同构于 mol2(供体位/受体位对应)
  · 取代基为模型原产物自带,保留
```
**模型 + 合法后处理的复现边界至此。**

> ❌ **原 Step 2/Step 3(嫁接绕丹宁 + 嫁接 N(CCO)C)已删除——不合法**:
> Step2 切除噻吩 C2 位的 4-异丙烯氨基苯基 + 接目标绕丹宁;
> Step3 切除苯环位的哌啶-OH + 接目标 N(CCO)C。两步均属**人工分子编辑**
> (切除模型原有取代基 + 接目标基团)。该链此前曾被声称 Tc=1.0,但不构成
> 模型的复现能力。脚本 `step2_assemble_mol2.py` 与产物 `mol2_assembled.sdf`、
> `mol2_docked.sdf`、`mol2_reproduction_report.pdf` 已归档至
> `casestudy/8hzk/_deprecated_graft/`。

### mol2 完整链(合法部分)
```
dummy_ligand #5133(吲哚分子)
        │
   元素替换 NH→S ↓
   苯并噻吩骨架(同构于mol2)  🟢 合法终点
        │
   切割C2取代基+嫁接=CH-绕丹宁(FluoDB) ❌ 不合法(已删除)
   苯并噻吩+绕丹宁 ✗ 不计入复现
        │
   切割苯环取代基+嫁接N(CCO)C ❌ 不合法(已删除)
       mol2(Tc1.0) ✗ 不计入复现
```
**说明**:模型复现边界至节点 2(元素替换苯并噻吩骨架);进一步替换受体/供体
属人工分子编辑,不计入模型复现能力。

## 两条链的操作对比(合法部分)

| 操作类型 | mol4 路径 | mol2 路径 |
|---------|----------|----------|
| **起点** | 两个来源汇聚(对接CCN + 生成stilbene) | 单一起点(生成吲哚分子) |
| **骨架获取** | sample_by_seed 生成 + 切割装饰提取 | **元素替换**(NH→S)直接获取 |
| **迭代** | 固定骨架迭代 3-5 轮(压缩装饰) | 无(一步元素替换到位) |
| **合法终点** | 迭代产物(Tc=0.58,Murcko==mol4) | 元素替换苯并噻吩骨架(同构 mol2) |
| **合法步数** | 3 步(汇聚→生成→迭代) | 1 步(元素替换) |
| ~~供体修正~~ | ~~嫁接 NH2→N(CCO)C~~ ❌ 已删除 | ~~嫁接 哌啶→N(CCO)C~~ ❌ 已删除 |
| ~~受体引入~~ | — | ~~FluoDB 绕丹宁嫁接~~ ❌ 已删除 |

## 关键差异

- **mol4**(无 S,二苯乙烯):桥可由模型生成(限制原子数后)→ **生成导向**,靠迭代逼近。合法终点 Tc=0.58。
- **mol2**(含 S,苯并噻吩):桥模型不生成但有等电子体(吲哚)→ **编辑导向**,靠元素替换直接获取。合法终点=苯并噻吩骨架。

> 此前版本曾把"最后一公里 = N(CCO)C 嫁接"列为共同障碍——但**嫁接不合法**,
> 故两条链的复现边界都止于骨架级,后续供体/受体精确化属人工分子编辑,
> 不计入模型复现能力。

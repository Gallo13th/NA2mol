# SPEC 04 — 关键功能片段库(D/A/π 独立,基于荧光规则)

> 替代 SPEC 01 的 BRICS 库。SPEC 01 用 BRICS 机械切分,会切断功能单元(如 stilbene 的 C=C 被切→片段池 0)。本 spec 用**荧光化学规则**提取**完整的单一角色功能单元**,产出三个独立库。

## 1. 目标
从 FluoDB-Full(55k 荧光分子)+ 荧光 D-π-A 化学规则,构建三个**独立的单一角色功能片段库**:
- **D 库**:完整的供体功能单元(三级胺+取代、咔唑、吲哚、TPA、吩噻嗪...)
- **A 库**:完整的受体功能单元(绕丹宁环、氰基乙烯、氰基丙烯酸、硝基、巴比妥...)
- **π 库**(可选):完整的共轭桥单元(stilbene、噻吩、苯、芴、联苯...)

**关键约束**:每个片段是**单一角色**的完整功能单元——不跨角色(不能是含 D+A+π 的整荧光分子),也不被切碎(如 stilbene 保持完整、绕丹宁环保持完整)。

## 2. 硬性约束
1. 数据源唯一:`fluor_util_2/FluoDB-Full.csv`。不读 known_mols(仅用于独立验收)。
2. **不用 BRICS**。用功能化学规则提取。
3. FluoDB 无 3D,参考构象用 RDKit 生成(本库主要作**匹配模板**,3D 为辅)。
4. 三库独立,角色不混淆。

## 3. 提取方法:功能锚定 + 角色边界切断

### 3.1 功能锚 SMARTS(定义各角色核心)
- **D 锚**:三级胺 `[NX3;H0]`、芳胺 `[NX3;H1][c]`、咔唑 `c1ccc2c(c1)[nH]c1ccccc12`、吲哚 `c1ccc2[nH]ccc2c1`、三苯胺 `N(c1ccccc1)c1ccccc1`、吩噻嗪/吩噁嗪/二苯并呋喃/二苯并噻吩/芴、吡咯/呋喃(作供体时)
- **A 锚**:硫代羰基 `C=S`、氰基 `C#N`、硝基 `[N+](=O)[O-]`、氰基丙烯酸 `C=C(C#N)C(=O)O`、绕丹宁环 `O=C1NC(=S)SC1`、巴比妥 `O=C1NC(=O)NC(=O)C1`、酰亚胺、砜 `S(=O)(=O)`
- **π 锚**:苯 `c1ccccc1`、联苯、stilbene `C(=Cc1ccccc1)c1ccccc1`、噻吩(作桥)、芴、共轭烯炔链

### 3.2 角色边界切断(核心——避免整分子一块)
全共轭 D-π-A 会被共轭分区当成一个块。必须在**角色转换键**处预切:
- **D-π 边界**:供体核心(如三级胺 N)连接到共轭桥(芳环/双键)的单键 → 切断。N + 其非共轭烷基取代 = D 片段;芳环 = π。
- **π-A 边界**:共轭桥连接到受体核心的键 → 切断。但**受体核心含其 α-共轭**(如 `C=C(C#N)` 的双键属于受体,因氰基乙烯是完整受体单元;`C=C(C#N)C(=O)O` 整个是氰基丙烯酸受体)。

### 3.3 单元提取规则
- **D 片段**:D 锚原子 + 直接相连的**非共轭取代基**(烷基、烷氧基、羟烷基),到第一个共轭(芳环/双键)边界停。
  - 例:三级胺连 CCO + 连芳环 → D 片段 = `N(C)CCO`(芳环不进 D,归 π)
  - 例:咔唑 → 整个富电子稠环 + N 上取代 = D 片段(稠环本身是供体)
  - 例:TPA → N + 三个苯 = D 片段(三苯胺整体供体)
- **A 片段**:A 锚 + 其**直接共轭环境**(使受体完整的原子)。
  - 例:绕丹宁 → 整个环 `O=C1NC(=S)SC1` = A 片段
  - 例:`C=C(C#N)` → 氰基乙烯双键 + 氰基 = A 片段
  - 例:`C=C(C#N)C(=O)O` → 整个氰基丙烯酸 = A 片段
  - 例:简单 `C#N` 连烷基 → `C#N` + α碳 = A 片段
- **π 片段**(可选):D 与 A 之间的共轭路径(切除 D/A 后的剩余共轭块)。
  - 例:stilbene `c1ccccc1CH=CHc2ccccc2` = π 片段(完整,不被 C=C 切)
  - 例:噻吩、苯、联苯、芴

### 3.4 流程
对每个 FluoDB 分子:
1. 锚定所有 D 核心、A 核心(用 3.1 SMARTS)
2. 在 D-π、π-A 角色边界切断(3.2)
3. 提取每个 D 单元(3.3 规则)→ D 库;每个 A 单元 → A 库;剩余共轭路径 → π 库
4. 去重(按规范化 SMILES)+ 频率统计 + 角色标注

## 4. 产出
`fragment_library/functional_blocks/`:
- `donors.pkl` / `acceptors.pkl` / `bridges.pkl`
- 每个片段:`{smiles, smarts, role, freq, n_ref, ref_3d_molblock(可选)}`
- `build_report.md`:各库规模、top 片段、验收结果

## 5. 验收(独立,用 known_mols)
1. **mol4 构件可提取**:从 FluoDB 能提取出 mol4 的三个独立单元——D=`N(C)CCO`、A=`C=C(C#N)`(氰基乙烯)、π=`stilbene`(二苯乙烯)。三者分别落在 D/A/π 库。
2. **单一角色不混淆**:抽检——D 库片段不含受体基团(C=S/C#N/硝基);A 库片段不含供体胺;π 库片段不含 D/A 特征基团。
3. **完整性**:stilbene 在 π 库是完整的(C=C 不断);绕丹宁在 A 库是完整环。
4. **覆盖**:D/A/π 三库非空,各覆盖多种功能单元类型。
5. **不泄露**:构建脚本不读 known_mols。

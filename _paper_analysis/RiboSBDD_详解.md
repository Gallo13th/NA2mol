## 0. 一句话概括

RiboSBDD = **在 TargetDiff 式 SE(3) 等变扩散框架上，做"蛋白→RNA 迁移 + 固定骨架下可微碱基旋转校正 + 保留冻结蛋白源的
自适应源-目标采样"**，并配套 RiboSBDDBench（8,006 个 RNA 口袋-配体实例、713 个测试口袋、11 项指标、按 PDB/RNA90
分组划分）的 RNA 结构药物设计（SBDD）生成方法。

三个卖点（论文自述贡献）：
1. **方法**：蛋白→RNA 几何迁移 + 可学习局部碱基校正 + 口袋条件原子数预测 + 自适应源-目标采样；
2. **基准**：RiboSBDDBench（8,006 实例、11 指标、分组划分防泄漏）；
3. **系统性发现**：蛋白预训练在 4 种架构上都改善共价几何；局部碱基校正提高接触与碱基朝向；自适应采样降低冲突。

## 1. 研究问题与总体设计

两个核心痛点（Fig. 1a）：
- **数据稀缺**：PDB 中 RNA-小分子复合物远少于蛋白-配体复合物；
- **口袋柔性**：RNA 局部核碱基重排会改变氢键边与堆积面，但几乎没有 apo/holo 配对结构或 MD 轨迹可用来监督口袋运动。

三个设计选择（Fig. 1b）：
1. **共享的全原子空间图**：蛋白/RNA 口袋放进同一套 24 类残基词表（20 种氨基酸 + 4 种核苷酸），保留残基身份但共享
   原子级特征与 3D 几何消息传递 → 蛋白预训练学到的 packing/H-bond/stacking 先验可迁移到 RNA；
2. **局部碱基校正**：固定糖磷酸骨架，只让核碱基绕糖苷键 χ 旋转；用有界合成旋转提供解析的"逆旋转"监督；用可微
   旋转把碱基校正头与配体去噪耦合；
3. **自适应源-目标采样**：推理时同时保留冻结的蛋白源模型与 RNA 目标模型，按"局部等密度投影 + 势函数引导的粒子
   重采样"组合两者的坐标提议；原子类型只由 RNA 目标决定，原子数由口袋条件预测器 p(N|C) 决定。

## 2. 方法学（Section 3 + Appendix A/B）

### 2.1 统一全原子表示与口袋条件扩散

**表示。** 口袋是一组原子点云 C = {(r_j, a_j, s_j)}_{j=1..M}：r_j 笛卡尔坐标，a_j 元素/结构特征，s_j 残基身份
（24 类：20 aa + 4 nt）。配体 L = (X, V)：N 个重原子坐标 X ∈ R^{3N}，原子类型 one-hot V ∈ {0,1}^{N×K}
（元素 + 芳香性类别）。把口袋与配体原子连成一张空间图：**共享原子特征 a_j 迁移蛋白的 3D packing 先验，残基身份 s_j
特化到 RNA 核苷酸**。图用 k=32 近邻边、按"源/目标属于配体与否"分 4 类边。

**扩散过程。** 沿用 TargetDiff：坐标做连续高斯扩散，原子类型做离散均匀类别扩散（Eq. 1）：

- q(X_t | X_0) = N(√ᾱ_t X_0, (1-ᾱ_t) I)
- q(v_t | v_0) = Cat(ᾱ_t v_0 + (1-ᾱ_t) 1/K)

去噪网络 F(X_t, V_t, C, t) = (X̂_0, ℓ_0) 预测干净坐标与未归一化类别 logits；损失 = 坐标 MSE + 原子类型
KL/交叉熵（Eq. 2，t=1 时退化为 NLL）。**原子数 N 在扩散前由独立的 p(N|C) 采样并固定**，不随轨迹变化。

**蛋白→RNA 迁移。** 在 CrossDocked2020 v1.1（Pocket2Mol/TargetDiff 的 10 万对标准 split；含约 2,000 个 Pocketome
口袋、pose RMSD ≤ 1.0 Å、30% 序列一致性聚类划分）上从零预训练源模型 F_s；选验证损失最低的 checkpoint；用其权重
初始化 RNA 目标 F_r，在 7,269 个 RNA 训练复合物上微调 75,000 updates（batch 16）。**F_s 保持冻结并保留到推理阶段**
用于自适应采样（3.3 节）。

### 2.2 可微的固定骨架局部碱基校正

**旋转算子。** 核碱基视为刚性平面芳香单元，绕糖苷键旋转：嘌呤绕 **C1′–N9**，嘧啶绕 **C1′–N1**；二面角分别定义为
O4′–C1′–N9–C4′ 与 O4′–C1′–N1–C2′。用 **Rodrigues 公式**实现 R(C, θ)，对 θ 可微；糖磷酸骨架固定不动。

**训练时的扰动。** 对每个可旋转残基采样 θ_r ~ TruncNorm(0, σ)（σ 名义 10°，截断最大 15°），并按扩散噪声比例
缩放：**a_{t,r} = √(t/T) · a_r**，得到扰动口袋 C_t = R(C, a_t)；以 0.25 概率保持不扰动（保证模型也见过观测口袋）。

**两遍前向 + 可微耦合。** 第一遍：对每个碱基做 mean-pool 得到节点表征，拼接 5 个时间/角度特征，经 64→1 的 MLP
（SiLU，tanh 输出，输出层零初始化 → 初始预测 0 旋转）得到归一化修正 b̂_{t,r} ∈ [-1,1]；缩放后
φ_{t,r} = b̂ · β_t · θ_max（θ_max = 15°），得到修正口袋 C̃_t = R(C_t, φ_t)。第二遍：在修正后的口袋上对**同一噪声
配体状态**再次去噪；因为 R 可微，配体重建损失可反传穿过口袋变换到校正头。

**多任务局部几何监督（Eq. 5–7）：**
- **角度损失 L_ang**：以合成逆旋转 a*_{t,r} 为监督目标（归一化角度 MSE）；
- **接触损失 L_contact**：以沉积界面的近邻对 S = {(i,j): d_ij ≤ 6 Å} 为真值，SmoothL1（1 Å 过渡尺度）监督
  修正口袋下的距离恢复；
- **位阻损失 L_steric**：单侧势，2.2 Å 阈值，仅在低噪声（t ≥ τ_steric）阶段生效——惩罚配体与观测口袋的原子重叠；
- 总损失 L = L_pos + L_v·type + L_ang + λ_c L_contact + λ_s L_steric。

**三阶段课程（每阶段 2,000 updates，batch 8，Table 3）：**
| 阶段 | 骨干 LR | 校正头 LR | λ_ang | λ_c | λ_s |
|---|---|---|---|---|---|
| Stage 1 | 1e-5 | 5e-4 | 100 | 0.2 | 0.0 |
| Stage 2 | 1e-5 | 5e-4 | 100 | 0.2 | 1.0 |
| Stage 3 | 1e-5 | 5e-3 | 100 | 1.0 | 1.0 |

（Stage 1 只用角度监督；Stage 2 打开接触损失；Stage 3 提高位阻权重。）

### 2.3 自适应源-目标采样（"两个模型的乘积"）

**两阶段采样（Algorithm 2/4）：**
- **Phase I（高噪声，t ≥ τ）**：目标模型先预测碱基校正（从观测口袋 C 出发、按当前噪声级），再在修正口袋上二次
  前向去噪配体；源模型在观测口袋上前向预测坐标。坐标按等密度组合（见下），累积粒子权重，按 ESS < B/2 做系统
  重采样（按原子数分层）。**只在这一阶段做碱基校正和重采样**。
- **Phase II（低噪声，t < τ）**：目标单次前向（用观测口袋），关闭校正与重采样，但仍保留源-目标坐标组合。

**反向级别。** 从原始 1,000 级扩散中选 **125 个反向级别**（63 个高噪声级 + 62 个低噪声级，含终端级），相邻级相差
8–9；源与目标各前向一次、目标额外 63 次 → **约 315 次网络评估/粒子**（比标准 TargetDiff 的 1,000 步少）。

**乘积专家（Eq. 8）。** 源/目标坐标提议 P_s = N(μ_s, σ_t²I)、P_r = N(μ_r, σ_t²I)，令 d_t = μ_r − μ_s：
P_r P_s = G(γ) · N(μ_s + γ d_t, σ_t²I)，其中 log G(γ) = −γ(1−γ)‖d_t‖² / (2σ_t²)。G 就是粒子权重势的来源。

**等密度超平面投影（Eq. 9–14）。** 不固定混合权重 γ，而是对每个噪声采样用等密度条件 P_r(X′) = P_s(X′) 解出
γ：γ = 1/2 − ⟨d_t, ε⟩ / (2‖d_t‖²)，再 clip 到 [0.5, 1.5]；当 ‖d_t‖² ≥ 1e-12 时令 γ = 1/2。未截断时，更新恰好落在
μ_s 与 μ_r 的垂直平分超平面上，只保留与 d_t 正交的噪声分量。**测试集上 94.3% 的反向步落在未截断区间内。**

**粒子重采样（Eq. 11）。** 每个口袋生成 B = 50 个粒子；按原子数 N 分层（保证同维度才比较势）；累积 log 权重
log w_b += log G(γ̂)，其中 γ̂ = clip(γ, 0, 1) 保证 log G ≤ 0（源/目标分歧越大惩罚越重）；算 ESS，ESS < B_N/2 时
做系统重采样并重置权重。**测试口袋上重采样在 18.4% 的 Phase I 步触发，平均每口袋 11.6 ± 2.4 次。**

**终端步（Eq. 17）。** 最后一级 t=1→0：不再加噪，两模型重新预测干净坐标，用上一随机级保存的 γ_last 做确定性
组合 X_0 = (1−γ_last) X̂_0^s + γ_last X̂_0^r；原子类型由目标做类别转移，权重不变。

**原子数预测 p(N|C)。** 独立 MLP：11 个口袋不变描述子（重原子数、回旋半径、3 个协方差特征值尺度、10 个最大原子
间距离的中位数、10/25/50/75/90% 径向分位数）→ N；RNA 训练集上训练 3 epochs（Adam 1e-3，batch 256），推理时加
σ=0.01 的归一化噪声、取整并裁剪到训练范围。

### 2.4 架构与训练细节

- **骨干**：TargetDiff 的 UniTransformer（9 层、hidden 128、16 头、k=32 近邻），1,000 级扩散；坐标用 sigmoid 噪声
  调度（10⁻⁷ 与 2×10⁻³ 端点），原子类型用 cosine 调度（offset 0.01），对称时间步采样。
- **为什么用 TargetDiff 而非 DiffSBDD**：直接预测 x̂_0/v̂_0 的参化更稳、且直接进入辅助几何损失与等密度均值提议；
  DiffSBDD 的多项式噪声参化在域迁移下退化更明显（其蛋白 checkpoint 在 CrossDocked 验证集上 RDKit 有效率 85.4%）。
- **校正头**：mean-pool 的碱基特征 + 5 个时间/角度特征 → 64 → 1 MLP（SiLU + tanh，零初始化）。
- **优化器**：RNA 训练 Adam，LR 5e-4，betas (0.95, 0.999)，梯度裁剪 8，plateau factor 0.6/patience 10/min LR 1e-6；
  局部几何训练 batch 8、3×2,000 updates，源模型冻结。

## 3. 评测内容（Section 4 + Appendix C/D）

### 3.1 数据：RiboSBDDBench

**构建流程（C.1，Table 11）：**
- 从 PDB 收集 **7,453 个含 RNA 的实验结构**，枚举 **3,670,853 个候选组分级实例**；
- 结构/化学清洗（去聚合物、水、离子、常见结晶添加剂、无碳组分、不可解析分子）；
- 保留"任一配体重原子距 RNA 重原子 ≤ 5 Å"的配体实例；
- 口袋 = 距配体重原子 ≤ 10 Å 的完整 RNA 残基的全部沉积原子；
- Broad 8,416 个，Clean 子集 7,469 个（要求 n_P/(n_P+n_R) ≤ 2/3，即局部配体环境中蛋白重原子占比 ≤ 2/3）；
- 模型可表示性检查（配体原子/键词表、RNA 残基映射、受体元素支持）→ **model-ready Broad 8,006 / Clean 7,113**，
  来自 **2,258 个 PDB entry**。

**Clean 测试集构成（Table 9）：** 73.07% 的测试口袋在 5 Å 内无蛋白重原子；35.06% 来自完全无蛋白链的 PDB entry；
59.33% 在 10 Å 内无蛋白上下文。

**划分（C.2）：** 以"共享 PDB ID 或 RNA90（90% 序列一致性）簇"为边做传递闭包，得到 14 个 split group；**训练
7,269 个 Broad 实例，测试 713 个 Clean 口袋**（24 个非 Clean 测试组成分被排除，训练/测试零共享 PDB/RNA90）。
测试集还预置了 OOD 子集：6 个未见 Rfam 家族（64 个口袋）、94 个 TM_pocket < 0.5 的口袋、82 个 s < 0.4 的
低配体相似口袋、未见骨架/未见配体等。

### 3.2 基线设置：4 架构 × 3 训练 regime

| 基线 | 实现 | 关键超参 |
|---|---|---|
| TargetDiff | UniTransformer，SE(3) 等变 | 9 层/128/16 头；1,000 步；sigmoid 坐标 + cosine 类型调度；直接预测 x̂_0 |
| DiffSBDD | 同架构，不同参化 | 1,000 步；多项式调度；预测噪声 |
| Pocket2Mol | GVP Transformer | 6 层，64 个 vector 通道；自回归逐原子生成 |
| GraphBP | encoder + context embedder | 各 6 层、hidden 256；自回归 normalizing flow |

每种架构都有三种 regime：**P**（纯蛋白训练、冻结后直接用于 RNA，原子数用 RNA 训练直方图）、**R**（RNA 从零训练）、
**P→R**（蛋白预训练 + RNA 微调），共 **12 个基线配置**。所有 P/P→R 共用同一 CrossDocked2020 预训练与 RNA 训练预算
（75,000 updates，batch 16）。另外还有模块消融（w/o Flexibility、w/o Sampling）与 16 行逐步消融（Table 18）。

### 3.3 指标（11 项 + 有效性漏斗）

**生成/有效性协议：** 每个测试口袋 50 次生成请求（713 × 50 = **35,650 次/模型**）；原子云→键重建（Open Babel
兜底）→ RDKit sanitize → 保留最大连通碎片且原子数 ≥ ⌈0.8N⌉ → 接受为有效分子；所有指标在**同一批接受的有效分子 G**
上计算，不丢样本。

| 维度 | 指标 | 定义要点 |
|---|---|---|
| 有效性 | Valid% | 接受的有效分子 / 35,650 |
| 化学 | QED | RDKit，0–1 |
| 化学 | SA（归一化） | SA = (10 − SA_raw)/9，越高越易合成 |
| 化学 | logP | 辛醇-水分配系数 |
| 几何 | JSD_BL / JSD_BA | 与 CrossDocked2020 配体的键长/键角分布 JS 距离（越小越好） |
| 相互作用 | Clash% | 按 vdW 半径、0.4 Å 容差判原子冲突，原子级加权（Eq. 22–23） |
| 相互作用 | Contact | 4 Å 重原子接触的参考残基召回率（Eq. 24–25，借鉴 PepFlow 的 BSR） |
| 相互作用 | AnnapuRNA IMP% | 生成姿态的统计势分数 < 参考配体的比例（Eq. 26） |
| 生成 | Novelty | 相对 RNA 训练配体 canonical SMILES 的新颖比例 |
| 生成 | Diversity | 口袋内 RDKit 指纹 Tanimoto 距离的均值（Eq. 27–28） |

**Top-5 推荐指标（Table 16）：** IMP%、Clash%、Contact、QED、SA（各报"无排序池均值 / Top-1 排序值"）。

**参考无关排序（Eq. 30）：** Score_rank(m) = 0.5·s̃(m) + 0.25·QED + 0.25·SA；先过 <5% clash、SA_raw < 6、QED ≥ 0.3
的候选门，再做 Top-1/3/5 分析；s̃ 把 AnnapuRNA 分数线性映射到 [0,1]（不依赖参考配体）。

**统计：** 10,000 次分组自助法（cluster bootstrap）95% CI（按 125 个 PDB entry 与 14 个 split group 两个层级），
以及精确符号检验；对关键比较报告 14 个组的方向一致性。

### 3.4 对照设计（很重要）

1. **16 行逐步消融（Table 18）**：从 Original TargetDiff P→R 出发，依次对齐更新步数/125 级/原子数先验（2a–2c），
   再逐步加刚性几何损失（5）、训练时碱基旋转（6）、固定混合（7）、等密度投影（8）、重采样（9）、直方图原子数
   （10）、全模型（11），最后把整套机制迁移到 DiffSBDD（12–14）。
2. **碱基校正的直接检验（Table 19）**：合成扰动（τ ∈ [500, 999]）的 MAE/RMSE/RMSD 与方向符号准确率；推理旋转
   方案（rigid / 连续 / 两阶段）；外部 **14 对 apo-holo RNA**（从 SMARTFlexDB 过滤，58 个活性碱基）上的
   apo→holo 方向预测准确率。
3. **全复合物冲突检验（Table 21）**：分别在 pocket.pdb、全部沉积 RNA 链、RNA+蛋白链上重算 Clash%。
4. **OOD/分层分析（D.5）**：蛋白自由 PDB、配体相似度分层、未见 Rfam、未见骨架、TM_pocket < 0.5、5 类功能 RNA。

- 相对 TargetDiff P（高质量基线）：Clash 5.73%→5.00%，IMP 63.86%→70.12%（+6.26 pp）。
- 有效性漏斗（Table 13）：RiboSBDD 接受 32,876/35,650 = 92.22%，其中 72.40%（25,812 次请求）产出 <5% clash 的
  有效姿态；TargetDiff P→R 分别为 88.74%/61.76%。

### 4.3 消融与机制归因（Table 1 + Table 18 + Table 19）

**模块级：**
- 去掉柔性（w/o Flexibility）：Clash 5.80%、IMP 65.27%、Contact 0.74 → 全模型 5.00%、70.12%、0.76；
- 去掉自适应采样（w/o Sampling）：Clash 9.20%、IMP 60.31%，但 **Contact 反而更高（0.78）**——说明接触覆盖不等于
  空间兼容，必须和 Clash 一起看。

**16 行逐步分解（Panel B，均给 125-PDB 与 14-group CI，方向一致组数）：**
- 几何损失（L_contact+L_steric，刚性口袋）：Clash −0.42 pp，IMP +2.15 pp；
- 训练+推理碱基旋转：Clash −0.38 pp，IMP +2.70 pp；
- 仅推理期旋转（infer φ=0 对比全模型）：Clash −0.18 pp，IMP +1.49 pp；
- 冻结蛋白源固定 50/50 混合：Clash −2.96 pp，IMP +5.07 pp（14/14 组）；
- 等密度投影：Clash −0.73 pp，IMP +2.36 pp；
- 粒子重采样：Clash −0.51 pp，IMP +2.38 pp；
- 结论：把更新预算/步数/原子数先验对齐后（2a–2c），Clash 只动 ≤0.44 pp、IMP 只动 ≤2.10 pp——**增益来自方法而非算力**。

**碱基校正的直接验证（Table 19）：**
- 合成扰动（τ∈[500,999]）：角度 MAE 6.38°→1.84°、RMSE 7.92°→2.41°、核碱基重原子 RMSD 0.42→0.13 Å，方向符号
  准确率 91.6%；
- 推理方案：刚性 5.18%/68.63%，连续旋转 5.14%/69.74%，**两阶段 5.00%/70.12%**（Clash/IMP）；
- 外部 apo→holo（14 对、58 个活性碱基）：方向预测准确率 **74.1%（43/58）**，14 对 bootstrap CI [63.8, 83.6]，
  符号检验 p = 0.0129；角度 MAE 7.62°→5.18°，RMSD 0.69→0.49 Å；Holo 帧上 Contact 0.74、Clash 6.24%、
  IMP 62.14%。

**跨架构迁移：** 把统一表征 + 碱基校正 + 自适应采样接到 DiffSBDD P→R 上：Valid 44.50%→51.28%，Clash
57.97%→38.62%，IMP 48.84%→60.75%（均优于 schedule/count 匹配的 DiffSBDD 对照）。

**原子数策略的权衡（Table 20）：** p(N|C) 去掉了小碎片，使 SA 从 0.67 降到 0.62、Div 从 0.75 降到 0.70
（"histogram count" 对照恢复），但换来了更低 Clash（5.36%→5.00%）与更高 IMP（67.18%→70.12%）；且
89.4% 的分子仍满足 SA_raw < 6。

**全复合物冲突（Table 21）：** 在 pocket.pdb / 全部沉积 RNA / RNA+蛋白上，RiboSBDD 的 Clash 为 5.00% /
5.07% / 9.09%，仍是 15 个配置中最低。

- **严格蛋白自由 PDB 子集（Table 22）**：Valid 93.14%、SA 0.67、Contact 0.77、Clash 4.86%、IMP 68.43%（全部
  基线中最好）。

- **未见 Rfam（64 个口袋、6 个家族）/ 未见骨架 / TM_pocket < 0.5（94 个口袋）/ 5 类功能 RNA**：RiboSBDD 在

- **定性（Fig. 4/附录）**：6VA2、9CPD 等口袋中，生成候选比晶体配体更小、QED/SA 更高，AnnapuRNA 能量分数

### 4.5 效率

- 125 级反向采样（约 315 NFE），**单张 A100 上每口袋 B=50 候选 14.2 s**；TargetDiff P→R 41.8 s、
  DiffSBDD P→R 45.3 s；步数匹配的 TargetDiff 对照 5.4 s、算力匹配 14.3 s。
- 每个 B=50 批次产出 **43.8 ± 3.6 个去重后唯一有效 SMILES**（对应 46.11 ± 3.24 个接受姿态）；TargetDiff P→R 为
  42.9 ± 3.9。

### 4.6 局限（论文自述 + 观感）

- 只建模**碱基绕糖苷键旋转**，骨架与整体构象固定；不覆盖骨架柔性、金属离子、水与质子化/互变异构。
- **无对接打分、无自由能、无湿实验**（作者明确把 "free-energy and wet-lab validation" 列为下一步）。
- 划分按 PDB/RNA90 分组而非全局 family/scaffold 排除，测试集中仍存在与训练配体完全相同（s=1.0）的口袋；
  泛化结论主要依赖他们另设的 OOD 子集。
- AnnapuRNA 统计势对"低有效性但条件 IMP% 高"的基线有选择偏差，论文用 per-request / low-clash yield 校正，但
  指标本身仍是知识型统计势而非实验亲和力。
- 方法模块较多（碱基校正 + 源模型 + 等密度投影 + 重采样 + 原子数预测），工程复杂度高；对超参/调度敏感
  （DiffSBDD 迁移后仍弱于 TargetDiff 骨干）。

## 5. 方法学评价（与 NA2smol 的对照要点）

**优点：**
1. **消融设计是该文最强项**：16 行逐步桥接 + 两个层级的 cluster bootstrap + 方向一致性 + 跨骨干（DiffSBDD）迁移，
   把"增益来自哪里"拆得很干净；NA2smol 的消融相对粗（4 个配置 + 部分统计）。
2. **基准贡献扎实**：8,006 实例、713 测试口袋、11 指标、PDB/RNA90 分组、OOD 子集；NA2smol 是 738 条记录 +
   37→27 个测试系统，数据规模与划分严谨性明显更弱。
3. **口袋柔性建模是差异化创新**：固定骨架 + 糖苷键旋转 + 合成逆旋转监督 + apo/holo 外部验证（74.1% 方向准确率），
   这是 NA2smol（刚性口袋）没有的。
4. **效率**：125 级/315 NFE、14.2 s/口袋，工程可用性较好。

**可质疑/局限：**
1. 评价全部基于 AnnapuRNA 统计势 + 接触/冲突几何，**没有对接或自由能**，也没有实验验证；对药物化学读者来说
   生物学相关性有限。
2. 与 NA2smol 相同的"首个"叙事风险：两文都声称填补同一空白（RNA 口袋 3D 生成），但 RiboSBDD 公开更早
   （2026-09-17）；NA2smol 若要引用它，需在 Discussion 中明确差异（BFN+ED 预训练 vs 扩散+碱基校正；湿实验 vs 纯计算）。
3. 数据和指标的"可复现性"承诺是 "accepted 后开源"，目前只有 OpenReview 匿名 PDF；NA2smol 的代码已公开（2026-10-29）。
4. 蛋白源模型的保留（自适应采样）本质上是"模型集成/蒸馏式采样"，对推理成本与实现细节敏感；论文用大量对照
   证明增益，但方法叙述较复杂，复现门槛高。

## 6. 结论

RiboSBDD 是一篇**方法 + 基准并重**的 RNA SBDD 生成工作：核心是"统一全原子表征的蛋白→RNA 迁移 + 可微碱基校正 +
保留冻结蛋白源的自适应采样"；评测体系（RiboSBDDBench、11 指标、713 测试口袋、分组划分、OOD 分层、16 行消融、
cluster bootstrap）是其最大亮点。最终结果上，它在 **Valid%、Contact、Clash%、AnnapuRNA IMP%** 四项核心指标上
全面领先 12 个基线（Contact 0.76、Clash 5.00%、IMP 70.12%），并能泛化到蛋白自由/未见 Rfam/低相似度/未见骨架等
OOD 子集；代价是 QED/SA/Diversity 略低、无对接与湿实验、泛化仍受 PDB/RNA90 划分与统计势指标的限制。
